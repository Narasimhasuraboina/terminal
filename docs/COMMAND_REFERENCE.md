# Linux Command Taxonomy & Classification

The interactive catalog contains over 1,000 categorized commands organized across 10 operational domains.

## Categories

1. **File Management (`files`)**: Directory traversal, file manipulation, symlinks, archives, and permissions (`ls`, `cd`, `cp`, `mv`, `tar`, `chmod`, `chown`).
2. **Process Management (`processes`)**: Process scheduling, signals, thread inspection, background tasks (`ps`, `top`, `htop`, `kill`, `pkill`, `nice`, `renice`).
3. **Text Processing (`text`)**: Stream editing, pattern matching, columnar formatting (`grep`, `awk`, `sed`, `cut`, `tr`, `sort`, `uniq`, `wc`).
4. **Networking & Sockets (`network`)**: Socket inspection, routing, DNS diagnostics, firewall tables (`ss`, `netstat`, `curl`, `ip`, `ping`, `traceroute`, `iptables`).
5. **Storage & Block I/O (`storage`)**: Filesystem usage, mount points, partition tables, block devices (`df`, `du`, `lsblk`, `mount`, `fdisk`, `sync`).
6. **System Diagnostics & Telemetry (`system`)**: Hardware detection, kernel ring buffer, uptime, load averages (`dmesg`, `uname`, `uptime`, `lscpu`, `free`).
7. **Security & Permissions (`security`)**: Audit logs, user accounts, sudo capabilities, SSH keys (`sudo`, `passwd`, `whoami`, `id`, `chage`, `ssh-keygen`).
8. **Package Management (`package`)**: Dependency resolution, repository updates, binary installations (`apt`, `dnf`, `pacman`, `dpkg`, `rpm`).
9. **Kernel & Device Internals (`kernel`)**: Kernel modules, sysctl tuning, eBPF probes, interrupts (`modprobe`, `lsmod`, `sysctl`, `bpftrace`, `insmod`).
10. **Hardware & Peripheral Buses (`hardware`)**: PCI devices, USB descriptors, thermal zones, battery status (`lspci`, `lsusb`, `sensors`, `dmidecode`).
