# Changelog

All notable changes to this project are documented in this file.

## [1.2.0] - 2026-09-08
### Added
- Comprehensive test suite for command catalog, VFS traversal, and sandbox integrity.
- Expanded practice sandbox with Nginx, Docker, JSON, TSV, and auth logs.
- Full architectural documentation suite across 12 dedicated reference guides.
- Rollup manual chunks optimization separating Three.js and catalog datasets.

### Changed
- Refactored missions modal and practice lab with delegated event listeners.
- Added canvas `roundRect` fallback checks for legacy browser compatibility.
- Hardened WebGL renderer initialization with safe fallback handling.

## [1.1.0] - 2026-08-28
### Added
- Expanded Linux command missions catalog to 1,000 commands.
- Interactive Practice Lab with dual split-screen terminal and live VFS navigator.
- Progressive 3-level hints accordion with automatic clipboard copy.

## [1.0.0] - 2026-08-28
### Initial Release
- 4-layer 3D motherboard architecture visualization.
- Interactive terminal UI with timeline scrubber.
- Web Audio API procedural sound effects.
- Real Linux syscall inspector and quiz mode.
