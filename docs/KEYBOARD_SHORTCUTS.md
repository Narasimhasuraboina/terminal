# 3D Visualizer Keyboard Shortcuts & Controls

Quick reference guide for navigating the 3D scene and controlling the simulation.

## Camera Navigation
| Key | Action |
|---|---|
| `1` | Preset: Full Motherboard Overview |
| `2` | Preset: User Space & Terminal Shell |
| `3` | Preset: Syscall Security Gate |
| `4` | Preset: CPU & RAM Memory Core |
| `5` | Preset: NVMe Storage & VFS Inodes |
| `Left Mouse Drag` | Orbit / Rotate Camera around target |
| `Right Mouse Drag` | Pan Camera position |
| `Mouse Scroll` | Zoom in / Zoom out |

## Simulation & Playback
| Key | Action |
|---|---|
| `Space` | Toggle Play / Pause simulation |
| `Arrow Left` | Step backward one stage |
| `Arrow Right` | Step forward one stage |
| `R` | Reset simulation to initial state |

## Terminal & Dialogs
| Key | Action |
|---|---|
| `Tab` | Autocomplete command name |
| `Arrow Up` | Previous command in history |
| `Arrow Down` | Next command in history |
| `Ctrl + L` | Clear terminal screen |
| `Ctrl + C` | Cancel current input line |
| `Esc` | Close any active modal dialog (Guide, Missions, Inspector, Quiz) |
